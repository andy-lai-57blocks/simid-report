DARK RELEASE: deploying changes nothing for users
The code goes to production in an "off" state. Turning SIMID on later is a dashboard setting, not a deploy.
① Default OFF
The RTB-connection SIMID toggle defaults to off. With it off, Jaeger never tells the DSP we support SIMID, so no DSP sends a SIMID creative.
② Backward compatible
The new smd field in the ad payload is additive. A renderer that doesn't know it ignores it, and an ad without it is an ordinary video.
③ Kill switch, no redeploy
Jaeger and Nautilus both check the two dashboard toggles. Turning either one off stops SIMID at that scope with no redeploy.
④ Fails safe
If a creative is slow or broken, Nemo removes the overlay and plays a normal clickable video. The video never goes blank. Verified in NPA.
